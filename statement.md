# Project Statement

## Problem Statement
Users often create weak or predictable passwords. This project provides a simple console program that generates random passwords based on user-selected requirements.

## Scope
The project is limited to password generation, basic password-strength analysis, and optional local saving of the generated password.

## Target Users
Students and general computer users who need a simple password-generation tool.

## High-Level Features
- Select password length.
- Select character types.
- Generate a random password.
- Check basic password strength.
- Optionally save the password to a text file.
